Waste & vent sizer

Commercial DWV. Place fixtures, connect them in flow order, and every pipe shows its running DFU and size. UPC Tables 702.1, 702.2, 703.2, 1002.2 and 1014.2.1.

Check before you rely on it. Values were transcribed from the UPC text (Tables 702.1, 702.2, 703.2, 1002.2, 1014.2.1) and still need checking against the printed 2024 edition and any local amendments. Tags show code (UPC) versus your design rules.
